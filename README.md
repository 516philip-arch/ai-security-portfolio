# AI 보안 학습 포트폴리오

> 6개월(2026-11-23 ~ 2027-05 하순) 동안 주 15시간씩 AI 보안을 혼자 공부하며 남기는 실습 기록과 점검 보고서입니다.

## 이 저장소는

- **두 축으로 공부합니다.** AI를 지키기(프롬프트 인젝션, LLM 앱 취약점) + AI로 지키기(AI 도구로 보안 업무 돕기)
- **결과물 중심입니다.** 자격증 대신, 직접 풀어 본 실습 기록과 AI 보안 점검 보고서를 쌓습니다.
- **기준은 OWASP Top 10 for LLM Applications (2025판)** 입니다.

## 공개 원칙

1. 정답 플래그, 비밀번호, 최종 페이로드는 그대로 적지 않고 일부를 가립니다.
2. 무엇을 시도했고 왜 실패·성공했는지, 막으려면 무엇이 필요한지에 집중합니다.
3. 자격증·시험 문제, 진행 중인 대회 문제는 공개하지 않습니다.
4. 허락받은 실습 환경에서만 시험하며, 실제 서비스를 허락 없이 시험하지 않습니다.
5. API 키, 개인정보, 회사 정보는 이 저장소에 올리지 않습니다.
