# AI 설명 대조 기록

AI(Claude 등)의 설명을 공식 문서와 비교해, 틀리거나 애매한 곳을 찾은 기록입니다. AI 답을 그대로 믿지 않고 확인하는 습관을 기르기 위해 매주 1건 이상 씁니다.

## 2026-11-24 · DNS가 뭐고 어떻게 작동하나

Claude에게 "DNS가 뭐고 어떻게 작동해?"라고 묻고, 평소처럼 쓴 답 9문장을 Cloudflare 'DNS란?' 문서와 하나씩 비교했습니다. 문서에 없는 내용은 다른 공식 문서에서 찾았습니다.

| 번호 | AI가 말한 것 | 공식 문서 | 판정 | 근거 링크 |
|---|---|---|---|---|
| 1 | DNS는 인터넷 전화번호부. 도메인 이름을 IP 주소로 바꿔 준다 | 같은 말 ('DNS란 무엇입니까?' 첫 문단) | 맞음 | [Cloudflare: DNS란?](https://www.cloudflare.com/ko-kr/learning/dns/what-is-dns/) |
| 2 | 인터넷에 연결된 모든 기기에 IP 주소가 있고, 그 주소로 서로를 찾는다 | 같은 말 (둘째 문단) | 맞음 | 위와 같음 |
| 3 | 브라우저는 먼저 자기 캐시, 없으면 운영체제 캐시를 본다 | 같은 말. 문서 아래쪽 'DNS 캐싱' 절의 '브라우저 DNS 캐싱'·'운영 체제 수준 DNS 캐싱' | 맞음 (처음엔 '문서에 없음'으로 봄) | 위와 같음 |
| 4 | 그다음 질문은 재귀 확인자로 간다. 보통 통신사가 운영한다 | 운영체제가 '인터넷 서비스 공급자(ISP) 내부의 재귀 확인자'로 보낸다고 씀. 구글 DNS 같은 다른 확인자도 있다고 함 | 맞음 (처음엔 '문서에 없음'으로 봄) | 위와 같음 |
| 5 | 재귀 확인자는 먼저 루트 서버에 묻는다. 루트 서버는 전 세계에 13대뿐이다 | ① 캐시에 .com 서버나 이름 서버 주소가 있으면 루트를 건너뛴다. ② "루트 서버가 13개밖에 없다"는 것은 **흔한 오해**라고 직접 적혀 있음. 13개는 **IP 주소** 수이고, 주소마다 여러 대가 있다 | **틀림** (13대). '먼저'도 캐시가 비었을 때만 | [Cloudflare: DNS 루트 서버](https://www.cloudflare.com/ko-kr/learning/dns/glossary/dns-root-server/), [root-servers.org](https://root-servers.org/) |
| 6 | 루트 서버는 .com 같은 TLD 서버 주소를 알려 준다 | 같은 말 ('8단계' 3번째) | 맞음 | Cloudflare: DNS란? |
| 7 | TLD 서버는 권한 있는 이름 서버 주소를, 그 서버는 마지막으로 IP 주소를 알려 준다 | 같은 말 ('8단계' 5~7번째) | 맞음 | 위와 같음 |
| 8 | 재귀 확인자는 IP 주소를 브라우저에 전하고, TTL 동안 캐시에 둔다 | 같은 말 ('8단계' 8번째, 'DNS 캐싱' 절) | 맞음 | 위와 같음 |
| 9 | DNS는 UDP 53번 포트로**만** 통신한다 | Cloudflare 'DNS란?'에는 없음. IETF 표준 RFC 7766은 DNS가 **TCP도 반드시 지원**해야 한다고 정함. 길을 감추는 보안 DNS(DoT·DoH)도 있음 | **틀림** ('만'이 틀림) | [RFC 7766](https://www.rfc-editor.org/rfc/rfc7766) |

**알게 된 것**

- 9문장 중 틀린 곳 2개(5번, 9번), 나머지 7개는 맞음.
- 틀린 두 문장 모두 **'뿐', '만'** 같은 단정하는 말에서 틀렸다. 이런 말이 나오면 먼저 의심한다.
- '문서에 없음'이라고 판단하기 전에 **문서 끝까지** 읽는다. 3·4번은 문서 아래쪽 'DNS 캐싱' 절에 있었다.
- 공식 문서도 낡을 수 있다. Cloudflare는 루트 서버가 "600개가 넘는다"고 썼지만, 루트 서버 운영자들의 사이트에는 2026-11-24 기준 2,046대(운영 기관 12곳)라고 나온다. 숫자는 그 숫자를 직접 관리하는 곳에서 확인한다.

## 이번 달에 알게 된 것

- AI가 자주 틀리거나 애매하게 말하는 부분: '뿐', '만', '항상' 같은 단정. 숫자(13대처럼 그럴듯한 숫자)
- 확인할 때 가장 믿을 만했던 출처: 그 일을 직접 맡은 곳의 문서 (루트 서버 수는 root-servers.org, DNS 규칙은 IETF RFC)
