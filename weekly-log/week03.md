# 3주차 · 보안의 기본 생각

날짜와 상관없이 순서대로 진행한다. 이번 주 분량은 18시간이다 (원래 15시간 + 책 6·7장 칸 3시간).

**이번 주 목표:** 보안 3원칙(기밀성·무결성·가용성), 인증과 권한 부여, HTTPS와 쿠키처럼 보안의 기본 생각을 잡는다. 사이사이에 책 6장(과도한 위임)과 7장(벡터와 임베딩)을 쓴다.

**최소 목표:** 3원칙과 인증·권한 부여를 내 말로 설명하고, 보안 소식 하나를 "3원칙 중 무엇이 깨졌나"로 나눠 볼 수 있다.

**2주차에서 바꾼 것:** 노트 09~15 대신 책 2부 원고(16장부터)를 쓴다. TryHackMe 룸은 답을 먼저 짐작하고 풀고, 기록은 Claude가 개인용으로 쓴다. 보안 소식은 Claude가 후보를 고른다. 3-5 ② 쿠키 보기 때 응답 헤더의 CSP 줄도 찾아본다.
